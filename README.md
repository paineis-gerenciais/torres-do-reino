# Torres do Reino: prévia da prova de desempenho

Este branch publica só o build estático da prévia do jogo **Torres do Reino** (versão 0.1.0, fase 1, marco 1), gerado em 2026-11-06 a partir do commit `139a9a3` do repositório de desenvolvimento. Ainda não é o jogo: a página de título leva à medição de desempenho (`#medir`), que roda uma cena sintética de formas geométricas por 60 segundos e mostra um resumo em texto para copiar.

- Dados fictícios; nenhuma arte, som ou marca de terceiros.
- Fora dos buscadores durante a fase de teste (`noindex` e `robots.txt`).
- Nada é enviado a servidor nenhum: a medição é local, no seu aparelho.
